# v70 世界資料層與瀏覽架構

這份文件記錄 #38 第 3 項「查找 → 世界」的正式邊界與最終資訊架構，避免世界頁後續膨脹成第二套 Wiki，或重新回到與實際遊玩思考順序不符的平行頁面。

## 定位

- 「資料」只保留玩家個人存檔記錄與進度：角色／農場／社區／收藏。
- 「查找」放遊戲本身的客觀參考資料，一級固定為 **世界／物品**，預設先進世界。
- 「社交」以 NPC 本人與玩家關係為中心；世界只處理人物與空間的關聯。
- 找魚不是查找的一級頁籤，也不是世界外另一套頁面。

## 最終瀏覽階層

世界採 **Map-first（地圖優先）、由大到小**：

`大世界地圖 → 區域 → 區域地圖 → 地點／釣點 → 具體資料`

例如：

`本島大世界地圖 → 煤矿森林 → 煤矿森林區域地圖`

進入區域後只分兩種主要內容：

### 地點

地點包含商店、建築、設施與特殊地點。

點地點後原地展開：

- 營業時間
- 解鎖／使用條件
- 可以做什麼
- 商品／服務
- 相關 NPC
- 其他相關入口

人物不與「地點／釣點」並列成區域的一級分類。人物是地點關聯資料；點 NPC 後進「社交 → NPC」。反向也成立：社交的今日行程點地點後，可回世界對應位置。

世界負責「人在哪裡／和哪個地方有關」；社交負責「這個人是誰／關係／禮物／完整行程」。

### 釣點

釣魚納入同一套空間階層：

`世界 → 區域 → 釣點 → 水域 → 魚`

區域的釣點模式使用區域範圍地圖，標示河流、池塘、瀑布、湖泊、特殊水域等。點某個釣點後，在目前世界頁顯示該處魚類，再依季節／天氣／時間等條件篩選。

既有找魚的點地圖互動與 fish data 繼續重用，但成為世界的一部分，不另複製魚資料。

同一水域若能從地點與釣點兩種路徑抵達，最後必須指向同一個 fishing spot stable ID。例如「秘密森林」地點內的可釣魚入口，與「煤矿森林 → 釣點 → 秘密森林水池」共用同一實體。

## 地圖層級

### 第一層：大世界

先選：

- 本島
- 姜岛
- 特殊區域

本島與姜岛使用遊戲地圖。

### 第二層：區域

從大世界地圖點區域，例如鹈鹕镇、煤矿森林、山區、海滩等，進入該區自己的區域地圖。

### 第三層：區域地圖模式

同一張區域地圖依模式切換標記：

- **地點模式**：商店／建築／設施／特殊地點。
- **釣點模式**：河流／湖／池塘／瀑布／其他水域。

區域頁不要做成 `地点 5｜人物 3｜找鱼` 類型的統計 dashboard；地圖本身才是主要導航。

## 快速反查

正常流程是從地圖由大到小，但世界另保留兩個輕量工具。

### 🎣 按條件找魚

適合「我知道今天的季節／天氣／時間，但不知道去哪裡釣」。

條件可包含：

- 季節
- 日期
- 天氣
- 遊戲時間
- 區域（可選）
- 魚名（可選）

結果以「魚 → 區域 → 具體釣點」呈現。點結果後直接定位世界對應的區域與釣點，不開另一套找魚頁。

### 👤 按條件找人

回答「今天／現在 NPC 在哪裡？」。

條件可使用：

- 年份
- 季節
- 日期／星期
- 天氣
- 遊戲時間
- 目前區域（可選）
- NPC 名稱（可選）

結果支援兩個方向：

- 點位置 → 世界對應地點
- 點人物 → 社交人物頁

此能力依賴 Roadmap 第 5 項 NPC 今日行程資料。行程資料完成前，不另外建立一套不可靠的簡化資料。

## 世界與社交的雙向關聯

例如：

`世界 → 煤矿森林 → 玛妮的牧场 → 玛妮 → 社交`

以及：

`社交 → 玛妮 → 今日行程 → 玛妮的牧场 → 世界`

人物與地點只維護 stable ID 關聯，不複製另一份人物資料。

## 資料模型

- 區域、地點、釣點、NPC、物品使用 stable ID。
- 顯示名稱遵守 Switch 遊戲本體 canonical name。
- 搜尋另外保存繁中／簡中／英文 aliases。
- 顯示名稱不得直接當資料 ID。
- 已有資料來源能重用就重用；不建立第二份人物、商店、魚類或物品資料庫。
- 商店資料若 `social-data-v50.js` 已存在就直接重用。
- 服務資料沿用既有可共用資料。
- 世界資料維持 lazy load，不增加總覽首次載入的 parser-blocking data。

## 世界頁主要回答

- 我在哪裡？
- 我要去哪裡？
- 這裡有什麼？
- 這裡能做什麼？
- 哪裡可以找到這個人？
- 哪裡可以釣到這條魚？

## 明確不做

- 不寫長篇地點背景故事或攻略。
- 不複製整套 Wiki 頁面。
- 不複製 NPC 全部資料。
- 不複製物品全部資料。
- 不複製魚類資料庫。
- 不在世界另外維護一份 NPC 行程。
- 不在 v70 宣稱所有特殊商店庫存／節慶例外已完整建模。
