# v70 世界資料層

這份文件記錄 #38 第 3 項「查找 → 世界」第一版的邊界，避免世界頁後續膨脹成第二套 Wiki。

## v1 目標

- 世界放在「查找」內，與物品／找魚同層；「資料」只保留玩家個人存檔記錄與進度（角色／農場／社區／收藏）。
- 用 stable ID 表示區域、地點與人物關聯；顯示名稱與繁／簡／英 aliases 分離。
- 地點卡優先回答：在哪個區域、何時可用、可以做什麼、相關人物、必要解鎖條件。
- 商店資料若 `social-data-v50.js` 已存在就直接重用，不建立第二份庫存。
- 可從世界卡跳到既有人物、找魚、物品與城鎮修復功能。
- 天氣先建立共用條件 ID；NPC 今日行程與更多「今天可以做什麼」規則之後直接使用。
- 世界資料採 lazy load，不增加總覽首次載入的 parser-blocking data。

## 明確不做

- 不寫長篇地點背景故事或攻略。
- 不複製整套 Wiki 頁面。
- 不在 v1 補完整 NPC 每日行程；該內容屬 roadmap 第 5 項。
- 不在 v1 宣稱所有特殊商店庫存／節慶例外已完整建模。

## 資料維護

`world-data-v70.js` 是 manual committed snapshot。來源與重建政策見 `docs/DATA_SOURCES.md`；若後續轉為 generator，必須保留 stable ID 並先和既有 snapshot 比對。
